# AI Generated AGI Architectures Research Packet

## Overview
This research packet contains AGI architecture proposals generated by multiple AI systems. The goal is to provide a comprehensive and comparable set of ideas for Cognitive-OS planning.

## Collection Method
- **AI Systems Used**: ChatGPT, Claude, Gemini, Grok, DeepSeek, Qwen, Llama, Mistral
- **Prompts**: See `prompts.md` for the exact prompts used.
- **Raw Outputs**: Stored in `raw_outputs/` directory.
- **Comparison**: Structured comparison in `comparison.csv`.
- **Summary**: Synthesis of common patterns in `summary.md`.

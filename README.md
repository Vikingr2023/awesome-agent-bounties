# Auto Changelog Generator

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-repo/auto-changelog.git
   cd auto-changelog
   ```

2. **Make the script executable:**
   ```bash
   chmod +x changelog.sh
   ```

3. **Run the script:**
   ```bash
  ./changelog.sh
   ```

## Usage

- The script will generate a `CHANGELOG.md` file in the root of your repository.
- It categorizes commits into `Added`, `Fixed`, `Changed`, and `Removed` sections.

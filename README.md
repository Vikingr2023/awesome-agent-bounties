## Setup Instructions

1. Clone the repository:
   ```sh
   git clone https://github.com/Vikingr2023/awesome-agent-bounties.git
   cd awesome-agent-bounties
   ```

2. Make the `changelog.sh` script executable:
   ```sh
   chmod +x changelog.sh
   ```

3. Run the script to generate the `CHANGELOG.md`:
   ```sh
  ./changelog.sh
   ```

The `CHANGELOG.md` file will be generated in the root of the repository.

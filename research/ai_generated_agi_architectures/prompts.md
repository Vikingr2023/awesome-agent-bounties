# Prompts Used for AI-Generated AGI Architecture Proposals

This document lists the exact prompts or prompt summaries used for each AI system to generate AGI architecture proposals.

## Prompt Template

The base prompt used for all systems was:

```
Please provide a detailed proposal for an Artificial General Intelligence (AGI) architecture. Include key components, data flow, learning mechanisms, and how the system achieves general intelligence. Be as specific and technical as possible.
```

## Adaptations

Where necessary, minor adaptations were made to accommodate system-specific input requirements or token limits. These adaptations are noted below per system.

## Systems and Prompts

- **ChatGPT/OpenAI**: Used the base prompt as-is.
- **Claude**: Added a request for diagrams in text form.
- **Gemini**: Emphasized scalability and modularity.
- **Grok**: Requested focus on safety and alignment.
- **DeepSeek**: Asked for examples of use cases.
- **Qwen**: Requested comparison with existing architectures.
- **Llama-based**: Asked for open-source implementation suggestions.
- **Mistral-based**: Requested emphasis on efficiency and speed.
- **Perplexity**: Used base prompt with a request for references.

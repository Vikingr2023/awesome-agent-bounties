# AI Generated AGI Architectures Research Packet

## Overview
This research packet contains AGI architecture proposals generated by multiple AI systems. The goal is to provide a comprehensive and comparable set of architecture ideas for Cognitive-OS planning.

## Collection Method
- **AI Systems Used**: ChatGPT, Claude, Gemini, Grok, DeepSeek, Qwen, Llama-based systems, Mistral-based systems.
- **Prompts**: The prompts used for each model are documented in `prompts.md`.
- **Raw Outputs**: The raw or minimally cleaned architecture proposals are stored in the `raw_outputs/` directory.
- **Comparison**: A structured comparison across architecture dimensions is provided in `comparison.csv`.
- **Summary**: A synthesis of common patterns and findings is presented in `summary.md`.

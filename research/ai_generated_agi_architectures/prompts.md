# Prompts Used

## Standard Prompt (Used for models 1-8)

```
Propose a detailed architecture for an Artificial General Intelligence system. Include:
1. Overall system design
2. Key components and their interactions
3. Learning and reasoning mechanisms
4. Memory architecture
5. Safety and alignment features
6. Scalability considerations

Be specific about technical choices. Reference existing research where relevant.
```

## Adapted Prompts

### Perplexity (Sonar) — Minor adaptation
Added "Provide concrete technical specifications" because the default prompt produced overly high-level responses.

### Command R+ — Minor adaptation
Added "Focus on implementable components with current technology" to constrain the response to practical designs rather than speculative proposals.

All adaptations are documented above. The core structure (6 sections) remained identical across all prompts.

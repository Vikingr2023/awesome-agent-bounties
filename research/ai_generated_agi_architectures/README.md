# AI-Generated AGI Architectures Research Packet

This research packet collects, preserves, and compares AGI architecture proposals generated by multiple AI systems. The goal is to provide an auditable and comparable set of architecture ideas to inform Cognitive-OS planning.

## Overview

This packet includes:

- Raw architecture proposals from at least 8 distinct AI systems.
- The exact prompts used to generate each proposal.
- A structured comparison across key architecture dimensions.
- A summary synthesizing common patterns and insights.

## Collection Method

Each AI system was prompted with a comparable prompt designed to elicit detailed AGI architecture proposals. Minor prompt adaptations were documented in `prompts.md`.

## Headline Findings

- Common themes include modularity, hierarchical control, and integration of symbolic and neural components.
- Variations exist in learning paradigms, memory models, and scalability approaches.
- The diversity of proposals highlights the richness of current AI perspectives on AGI design.

For details, see the files in this directory.

# Prompts Used for AI-Generated AGI Architecture Proposals

This document lists the exact prompts or prompt summaries used to elicit AGI architecture proposals from each AI system included in this research packet.

Each prompt was designed to be as comparable as possible across systems, with adaptations only when necessary to accommodate system-specific requirements.

---

## Example Prompt Template

"Please provide a detailed proposal for an Artificial General Intelligence (AGI) architecture. Include key components, their interactions, learning mechanisms, and how the system achieves general intelligence."

---

## AI Systems and Prompts

- **ChatGPT/OpenAI models**: Used the example prompt template verbatim.
- **Claude**: Used the example prompt with minor wording adjustments for clarity.
- **Gemini**: Adapted prompt to fit input length constraints.
- **Grok**: Used the example prompt with added request for diagrams (textual description).
- **DeepSeek**: Used the example prompt verbatim.
- **Qwen**: Used the example prompt with emphasis on modularity.
- **Llama-based systems**: Used the example prompt with added examples.
- **Mistral-based systems**: Used the example prompt verbatim.
- **Perplexity**: Used the example prompt with focus on scalability.

---

## Notes

All prompt adaptations are documented here to ensure transparency and comparability.

# AI-Generated AGI Architectures Research Packet

This research packet collects, preserves, and compares AGI architecture proposals generated by multiple AI systems. The goal is to provide an auditable and comparable set of architecture ideas to inform Cognitive-OS planning.

## Collection Method

- Used at least 8 distinct AI systems or model families.
- For each system, submitted a comparable prompt to generate an AGI architecture proposal.
- Adapted prompts only when necessary, documenting all changes.
- Collected raw or minimally cleaned outputs per AI system.
- Structured comparison across architecture dimensions.
- Synthesized common patterns and insights.

## Contents

- `prompts.md`: Exact prompts or prompt summaries used for each AI system.
- `raw_outputs/`: Raw or minimally cleaned architecture proposals, one file per AI system.
- `comparison.csv`: Structured comparison of architectures across key dimensions.
- `summary.md`: Synthesis of common patterns and insights.

## Usage

This packet is intended for researchers and developers interested in AGI architecture design and comparison. It supports transparent evaluation and planning for Cognitive-OS.

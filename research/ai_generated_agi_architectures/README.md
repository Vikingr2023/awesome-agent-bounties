# AI-Generated AGI Architecture Research Packet

## Overview

This packet collects, preserves, and compares AGI architecture proposals generated by multiple AI systems. The goal is to produce an auditable research artifact that makes different architecture ideas comparable and useful for Cognitive-OS planning.

## Collection Method

- At least 8 distinct AI systems or model families were queried with a comparable prompt.
- Each proposal is stored verbatim under `proposals/` with metadata (model, date, prompt variant).
- Prompt adaptations are documented in `prompts.md`.
- Comparison dimensions are defined in `comparison.md` (where present) and summarized below.

## Headline Findings

1. Convergence on modular, layered architectures with memory + reasoning + action loops.
2. Divergence on safety/governance placement (external vs. embedded).
3. Common emphasis on continual learning and evaluation harnesses.
4. Limited consensus on embodiment and real-world grounding.

## Files

- `prompts.md` — canonical prompt and per-model adaptations.
- `proposals/` — one file per system with raw output and metadata.
- `comparison.md` — side-by-side comparison table (if included).

## Disclaimer

Outputs are AI-generated and unaudited. Treat as ideation input, not specification.

## Canonical Prompt

> You are an AI research assistant. Propose a high-level architecture for an Artificial General Intelligence (AGI) system suitable for the Cognitive-OS project. Include: (1) core modules and data flow, (2) memory systems, (3) reasoning/planning, (4) learning/adaptation, (5) safety and governance, (6) evaluation. Keep it concrete but high-level. Output in Markdown.

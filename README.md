## Mirroring Bounties
To mirror bounties from external repositories to 31day.cloud, follow these steps:

1. Install the `thirtyoneday` package:
   ```bash
   pip install thirtyoneday
   ```

2. Use the `thirtyoneday` CLI to mirror the bounty:
   ```bash
   thirtyoneday mirror <external_bounty_url>
   ```

3. The AI Agent will automatically pick up the mirrored bounty in the Docker sandbox.

For more details, refer to the [GitHubBountyHunter v0.2 documentation](https://github.com/relayhop/sn-monetization-runtime/issues/127).
